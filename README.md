**Mein Beitrag:** Entwicklung des MindRails-Projekts mit KI-Unterstützung; Zusammenführung von Plugins, lokaler App und MCP-Werkzeugen. Herkunft und Abgrenzung zu Jev sind im Repository dokumentiert.
